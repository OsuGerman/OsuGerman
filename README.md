## Osu Profile Checker

This repository now includes a small Python script to check the profile of an osu! player.

### Usage
1. Install the `requests` package: `pip install requests`
2. Set the `OSU_API_KEY` environment variable with your osu! API key.
3. Run `python osu_profile_checker.py <username>` to view profile info for a player.
   You can also start the script without arguments and it will prompt for your
   osu! username interactively.

The output now includes:
* A brief analysis of the player's strengths
* Their improvement rate based on pp gained per day since joining
* The favourite beatmap creator from their best plays
* Average star rating, approach rate and overall difficulty of top plays
* Average accuracy and most used mod across best scores
