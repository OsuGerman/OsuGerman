### Featured project — TIEFGANG

<a href="https://osugerman.github.io/Tiefgang-Releases/">
  <img src="https://raw.githubusercontent.com/OsuGerman/Tiefgang-Releases/main/media/banner.jpg" alt="TIEFGANG – deep-sea roguelike shooter" width="100%">
</a>

**A fast deep-sea roguelike shooter built in Godot 4** — dive through four sunken worlds of the Thalassari ruins, fight 30+ enemy types and six bosses, and build absurd loadouts from 9 weapons, 6 abilities, 55 charms and 21 elemental blessings.

- Procedural rooms, objectives and corrupted portals with modifiers · run saving and run history
- Active-reload weapons, combo blade, elemental reactions, boss phases with death sequences
- Self-built tooling: headless test suite (GUT, 250+ tests), smoke tests, probes for geometry/animation clipping, versioned builds and an auto-updater shipping test builds via GitHub Releases
- Co-op for up to four players in testing (ENet, lobby codes, UPnP)
