This repository (`OsuGerman/OsuGerman`) is a **GitHub profile README** — the special repository whose `README.md` is rendered on the owner's GitHub profile page.

### Key facts

- The repo contains **only** `README.md` (Markdown/HTML).
- There is **no application code**, no dependencies, no build system, no tests, and no linting configuration.
